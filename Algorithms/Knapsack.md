- Think of a robber filling his bag
	- There's only so much weight he can carry
	- Want to maximize value of things that are taken without exceeding carrying capacity
		- Each element has a weight and a value
		- In some variations, robber can take fractions of items. In others, it cant

### Procedure for fractional version
1) Assume items are sorted by decreasing value per weight `v1/w1 > v2/w2 ...`
2) Take as much of item with greatest value per weight while not exceeding carrying capacity
